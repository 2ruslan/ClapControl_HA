# Використання Clap Control

Повна інструкція встановлення, налаштування, діагностики та обмежень знаходиться у [README.md](README.md).

Почніть із `test_mode: true`, виберіть аудіовхід на сторінці застосунку і відкрийте Вебінтерфейс. Перевірте лічильники хлопків та серій, додайте сцени, налаштуйте порядок і лише потім вимкніть тестування. Зміни Ingress набирають чинності після натискання «Зберегти налаштування».

Після редагування опцій на стандартній сторінці App перезапустіть застосунок. Змінені опції Supervisor замінюють увесь набір налаштувань Ingress. Для щоденних змін використовуйте Ingress.
