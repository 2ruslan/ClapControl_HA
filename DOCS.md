# Використання Clap Control

Усі налаштування детектора та сцен доступні через **Вебінтерфейс**. Стандартна сторінка Home Assistant використовується лише для системних параметрів, зокрема вибору аудіопристрою.

Виберіть аудіовхід, запустіть застосунок і відкрийте Вебінтерфейс. Увімкніть «Тестування хлопків» і натисніть «Зберегти налаштування». Перевірте лічильники хлопків та серій, додайте сцени, налаштуйте порядок і лише потім вимкніть тестування.

Версія 1.1.0 автоматично переносить старі налаштування під час першого запуску. Надалі вони зберігаються тільки у вебпанелі; старі опції Supervisor не мають впливу. Позиція циклу зберігається. Перед оновленням створіть резервну копію застосунку.
