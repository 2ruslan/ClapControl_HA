# Перевірка на Home Assistant OS

Це список приймальних випробувань на реальному обладнанні. Пункти нижче ще потрібно виконати на цільовому міні-ПК; автоматичні тести їх не підтверджують.

Перевірено під час розробки 24.10.2026: 43 автоматичні тести на Windows, Python 3.12.14 і NumPy 2.3.5; перевірка синтаксису JavaScript; завантаження і візуальний огляд панелі в браузері з тестовими даними. Docker daemon був недоступний, тому складання Linux-образу та інтеграція з реальним Supervisor/PulseAudio не перевірені. Додано CI для Python 3.13 і Docker; його результат стане відомим після запуску в GitHub.

- [ ] Локальне складання та встановлення на amd64 без вимкнення захисного режиму.
- [ ] Ingress відкривається на комп’ютері й телефоні; зовнішніх портів немає.
- [ ] Built-in Audio Analog Stereo або заданий PulseAudio source підключається.
- [ ] Після збереження налаштувань мікрофон перепідключається.
- [ ] У тестуванні 30 серій із 2 хлопків: записати відстань, gain, чутливість і кількість пропущених/зайвих серій.
- [ ] Повторити для 1 і 3 хлопків, коротких і надто довгих інтервалів.
- [ ] Мовлення, музика, стукіт, двері, звичайний фон протягом 10 хвилин: записати хибні серії; підібрати чутливість.
- [ ] Тестування не змінює сцени й не надсилає події.
- [ ] Цикли з 1, 2, 3 і довшим списком сцен працюють у заданому порядку.
- [ ] Після однієї активації перезапустити застосунок: наступною буде наступна сцена.
- [ ] Ручне керування світлом не зсуває цикл.
- [ ] Видалити наступну сцену в HA: видно помилку, позиція не змінюється. Відновити сцену або відредагувати список.
- [ ] Перезапустити аудіосистему або тимчасово від’єднати мікрофон: видно помилку, потім автоматичне відновлення.
- [ ] Тимчасово зупинити Core: детектор і панель живі, API повертає помилку; після відновлення повторна серія працює.
- [ ] Подія містить кількість хлопків, UTC-час, entity_id, номер від 1 і розмір списку.
- [ ] Перезавантажити HA OS: автозапуск, налаштування і цикл відновлюються.
- [ ] Перевірити CPU/RAM у простої, при музиці та протягом 24 годин; пам’ять не зростає, журнал не містить аудіоданих.

Зберігайте результати, версію HA OS/Core, модель мікрофона й параметри. Не вважайте нуль хибних спрацьовувань на синтетичних тестах доказом нульової частоти помилок у кімнаті.
